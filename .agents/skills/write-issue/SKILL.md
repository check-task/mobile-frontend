---
name: write-issue
description: 이 저장소의 GitHub 이슈를 작성할 때 사용.
---

1. `.github/ISSUE_TEMPLATE/issue.yml`을 읽고 필드 순서대로 채운다.
2. 제목은 `[태그] 작업 내용` (예: `[Setting] 에이전트 설정 정비`).
3. 브랜치 유형은 `write-commit` 스킬의 태그 중 하나(영문 소문자), 브랜치 작업 내용은 영어 kebab-case로 쓴다.
4. 상세 설명과 작업 체크리스트 항목을 1:1로 맞춘다.
5. 범위가 크면 이슈를 나누는 안을 함께 제안한다.
