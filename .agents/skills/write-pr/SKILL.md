---
name: write-pr
description: 이 저장소의 PR 제목과 본문을 작성할 때 사용.
---

1. `.github/pull_request_template.md`를 읽고 섹션 구성을 그대로 따른다. 제목 안내 섹션은 본문에서 지운다.
2. 제목은 `[태그/#이슈번호] 작업 내용` (예: `[Setting/#23] Expo SDK 57 업그레이드`). 태그와 이슈 번호는 브랜치명 `<태그>/<번호>-<작업>`에서 가져온다.
3. 관련 이슈번호에 `Closes #이슈번호`를 넣는다.
4. 작업 세부 내용은 `git log dev..HEAD`와 `git diff dev...HEAD --stat`를 근거로, 무엇을 왜 바꿨는지 쓴다.
5. 실행한 검증과 결과를 기타에 적는다. 확인하지 않은 것은 확인하지 않았다고 쓴다.
6. 대상 브랜치는 `dev`.
